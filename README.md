# 🤖 AI Super App — веб-версия

Это тот же AI-помощник, но в виде **сайта** (один файл `index.html`).
Открывается в любом браузере, интерфейс как у чата.

## Что умеет
- 💬 **Чат** — ответы на вопросы
- 👨‍💻 **Программист** — помощь с кодом
- 🎨 **Фото** — генерация картинок по описанию
- 🔊 **Озвучка** — текст в голос (аудио-плеер)

## Как пользоваться
1. Открой `index.html` двойным кликом (или опубликуй на GitHub Pages).
2. Нажми **⚙️ Настройки** → вставь свой **API-ключ OpenAI** → Сохранить.
3. Выбери режим сверху и напиши сообщение.

Ключ хранится только в твоём браузере (localStorage).

---

## ⚠️ Важно про безопасность

Этот сайт обращается к AI-API **напрямую из браузера**, поэтому:

- Это **личный инструмент** для себя. Ключ виден в браузере.
- НЕ публикуй этот сайт с уже вписанным ключом для всех — любой сможет его утащить и тратить твои деньги.
- Если нужен **публичный сайт для многих пользователей**, ключ нельзя держать в браузере — нужен небольшой сервер-прокси (backend), который хранит ключ у себя и передаёт запросы к API. Могу сделать такой — попроси.

---

## Режимы, которые требуют backend

**Редактирование фото** и **генерация видео** технически сложнее делать чисто в браузере (загрузка файлов, долгие задачи, отдельные провайдеры). Это лучше делать через небольшой backend. Если нужно — добавлю.

---

## Публикация на GitHub Pages

Точно так же, как с сайтом Dodge SRT: загрузи `index.html` в репозиторий, включи Pages в Settings. После этого ссылку можно подключить к Telegram-боту как Mini App.
